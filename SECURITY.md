# Segurança

**Atenção:** a versão atual é um MVP de desenvolvimento, sem autenticação/autorização. Não publique a API na internet sem implementar autenticação, autorização, HTTPS, restrições de origem e gestão segura de credenciais.

Não abra issues públicas com segredos, tokens ou dados sensíveis. Para relatar uma vulnerabilidade, contate o mantenedor por canal privado indicado no perfil do repositório.
